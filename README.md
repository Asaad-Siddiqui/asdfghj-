# 🌍 TRAVELLO

**AI-Powered Green & Inclusive Travel Platform**

> Travel Better. Leave a Lighter Footprint.

TRAVELLO is a hackathon prototype for Smart India Hackathon PS5: Green & Inclusive Travel — Smart Sustainable and Accessible Hospitality.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the application.

## 🏗️ Tech Stack

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS** for styling
- **React Router** for navigation
- **Recharts** for data visualization
- **Lucide React** for icons

## 📱 Features

### Traveler Side
- 🌍 **Destination Discovery** — Explore destinations with sustainability scores
- 📊 **Sustainability Profile** — Real-time destination health with factor breakdowns
- 🗺️ **AI Trip Planner** — Personalized sustainable itineraries with explainable AI
- 🏆 **Challenges** — Destination-specific responsible travel challenges
- 📸 **Evidence Submission** — Photo, location, timestamp verification flow
- 📋 **Issue Reporting** — Report waste, overcrowding, accessibility issues
- 📊 **Impact Profile** — Track your sustainable travel journey
- 👥 **Social Feed** — Community posts and achievements
- 🎯 **Creator Campaigns** — Follow responsible travel creators

### Destination Manager Side
- 📊 **Dashboard** — Destination health metrics and analytics
- 🤖 **AI Insights** — Aggregated intelligence from traveler reports
- 📈 **Charts & Trends** — Issue categories, weekly trends
- ⚡ **Recommended Actions** — AI-powered intervention suggestions

## 🔄 The Feedback Loop

```
Traveler Actions → AI Aggregation → Destination Intelligence → Better Recommendations → Positive Impact
```

## 🏆 Hackathon Demo Flow

1. **Discover** → Explore Matheran's sustainability profile
2. **Plan** → Generate a personalized trip with AI
3. **Challenge** → Complete a Waste-Free Trail challenge
4. **Evidence** → Submit photo + location + timestamp
5. **Report** → Report a waste hotspot
6. **Dashboard** → See AI-aggregated intelligence
7. **Loop** → New intelligence influences recommendations
