# TRAVELLO — Homepage Context

## Purpose

The homepage must make TRAVELLO immediately understandable as a modern travel product, not an environmental compliance portal.

The experience should prioritize discovery, travel inspiration and useful responsible-travel actions.

## Landing page

Hero headline:

TRAVEL BETTER.
LEAVE A LIGHTER FOOTPRINT.

Supporting copy:

Discover places.
Experience them responsibly.
Make every journey count.

Primary CTA:
Explore Destinations

Secondary CTA:
See How It Works

## Landing page sections

1. Hero travel visual
2. Product value statement
3. Discover → Act → Earn → Influence
4. Trending destinations
5. Responsible challenges
6. Creator campaigns
7. Sustainability + accessibility explanation
8. Traveler-generated intelligence
9. Sustainable businesses/community
10. Final CTA

## Landing visual direction

Use large travel photography and premium modern layouts.

Avoid:
- generic green NGO styling
- overly technical dashboards
- cluttered statistics
- excessive environmental icons

## Authenticated home

Top:
- personalized greeting
- destination search
- notification/profile controls

Recommended sections:
1. Continue your journey
2. Recommended destination
3. Responsible challenge for you
4. Trending travel posts
5. Creator campaign
6. Personal impact summary
7. Nearby/relevant sustainable businesses

## Feed card

A travel post should show:
- profile
- destination
- media
- caption
- challenge/achievement if relevant
- likes
- comments
- share

Important:
Responsible actions should appear naturally inside travel content.

Example:
A Matheran travel photo can show:
“🏆 Completed: Waste-Free Trail”

## Homepage recommendation

Recommendations should be understandable:
“Recommended because Matheran has high visitor pressure.”

Do not create mysterious AI recommendations with no explanation.

## Empty states

If a new account has no activity:
- show recommended destinations
- show beginner challenges
- explain how points work
- invite the user to complete the first challenge

## Mobile

On mobile:
- keep search prominent
- use compact destination cards
- use bottom navigation
- prioritize challenge CTA
- keep social feed visually immersive
