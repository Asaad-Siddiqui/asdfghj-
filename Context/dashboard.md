# TRAVELLO — Destination Intelligence Dashboard

## Purpose

The dashboard demonstrates the second major side of the ecosystem:

Traveler activity → destination intelligence → better decisions.

## Main dashboard

Example:
Matheran Destination Dashboard

Metrics:
- Sustainability score
- Visitor pressure
- Open issues
- Challenges completed
- Active campaigns

## Issue analytics

Show:
- top issue categories
- issue trend
- high-priority reports
- recent reports

Example:
Waste — 42%
Overcrowding — 28%
Accessibility — 14%
Water — 10%

These can be demo values and should be marked accordingly where needed.

## Issue map

Display approximate/demo issue locations.

Marker colors can represent status or priority.

Clicking a marker opens:
- category
- report count
- priority
- status
- latest report

## Report detail

Show:
- evidence
- location
- category
- description
- created time
- status
- review actions

## Dashboard recommendations

The dashboard can produce simple action suggestions.

Example:
“Waste reports increased near the north trail. Consider adding/relocating waste points.”

Recommendations should be framed as decision support, not automatic government orders.

## Analytics

Useful MVP charts:
- issue categories
- challenge participation
- sustainability factor breakdown
- recent issue trend

Avoid a dashboard full of decorative charts.

Every chart should answer a useful question.
