# TRAVELLO — Traveler Profile Context

## Purpose

The profile makes responsible travel progress personal.

## Profile header

Show:
- avatar
- name
- short bio
- impact points
- badges
- challenges
- destinations

## Impact summary

Example:
980 Impact Points
12 Badges
26 Challenges
7 Destinations

If demo data is used, it should be understood as prototype data.

## Badges

Grid of earned and locked badges.

## Journey history

Show destinations visited and completed challenges.

## Achievements

Show:
- recent badge
- challenge
- date
- points

## Settings

Potential:
- profile
- notifications
- privacy
- accessibility preferences
- logout

## Privacy

Users should control public profile details where practical.

## Profile role

The profile can indicate:
- Traveler
- Creator
- Business
- Destination Manager

Do not expose admin-only functionality just because a role label appears in the UI.
