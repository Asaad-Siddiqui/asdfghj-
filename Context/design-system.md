# TRAVELLO — Design System Context

## Product personality

TRAVELLO should feel:
- modern
- premium
- adventurous
- human
- trustworthy
- environmentally conscious

It should NOT feel:
- like an NGO portal
- like a school project
- like a generic admin template
- like a booking clone

## Visual direction

Base palette:
- deep forest/emerald green
- warm off-white
- charcoal/dark text
- earthy neutrals
- restrained accent colors

Do not make every component green.

Use travel photography as a major source of visual energy.

## Typography

Use a modern sans-serif typeface.

Strong hierarchy:
- large editorial hero headings
- clear section titles
- readable body text
- compact metadata

## Cards

Use:
- rounded corners
- clean borders/shadows
- strong imagery
- generous spacing

Avoid excessive glassmorphism.

## Buttons

Primary:
high contrast and visually obvious.

Secondary:
outlined/subtle.

Danger:
reserved for destructive actions.

## Icons

Use a consistent icon library.

Do not mix many icon styles.

## Micro-interactions

Useful:
- hover elevation
- button feedback
- progress animation
- badge reveal
- success animation
- smooth page transitions where appropriate

Avoid excessive animations.

## Accessibility

Maintain:
- keyboard navigation
- visible focus
- sufficient contrast
- descriptive labels
- semantic HTML
- accessible forms

## Responsive behavior

Desktop:
- spacious layouts
- multi-column cards

Tablet:
- reduced columns

Mobile:
- single-column primary content
- bottom navigation
- sticky important CTA when useful

## Data visualization

Charts should be minimal and readable.

Use labels and legends.

Do not rely only on color to communicate status.

## Loading states

Use skeletons for content-heavy pages.

## Empty states

Every major collection should have a useful empty state.

## Error states

Use friendly, actionable messages.

## Overall rule

Visual consistency is more important than adding more decoration.
