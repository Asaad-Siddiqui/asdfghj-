# TRAVELLO — Social Travel Context

## Purpose

Social behavior is the influence layer of the product.

The platform should feel like travel discovery with responsible behavior naturally embedded.

## Feed

Feed content:
- travel photos
- travel stories/posts
- creator content
- challenge achievements
- destination activity

## Post

Fields:
- author
- destination
- media
- caption
- challenge association if any
- created_at

Interactions:
- like
- comment if implemented
- share
- open destination
- open author

## Responsible achievement

Example:
“I completed the Waste-Free Trail in Matheran.”

Display:
🏆 Challenge completed
+25 impact points

## Social loop

Traveler completes challenge
→ achievement becomes content
→ followers see it
→ followers explore challenge
→ participation increases

## Feed ranking

For MVP use simple ordering:
- recent
- followed creators
- destination relevance
- popular content

Do not build a complex social recommendation algorithm.

## Moderation

Future-ready structure:
- report post
- block user
- moderation status

For MVP, basic safeguards are sufficient.

## Empty feed

Show:
- recommended destinations
- creator campaigns
- beginner challenges

## Visual priority

Media should be prominent.

The feed should look like a travel product, not a sustainability report.
