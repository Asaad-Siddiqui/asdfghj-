# TRAVELLO — Destination Context

## Purpose

The Destination Hub is the main place where travel discovery becomes responsible decision-making.

## Prototype destinations

Use a small curated set:
- Matheran
- Goa
- Manali

Three polished destinations are better than dozens of empty records.

## Destination card

Show:
- image
- name
- location
- sustainability score
- accessibility summary
- short descriptor
- Explore CTA

## Destination Hub structure

### Hero
- destination image
- destination name
- region
- sustainability score
- accessibility overview
- visitor pressure

CTA:
Start Responsible Journey

### Snapshot
Show factors such as:
- Waste
- Water
- Nature
- Visitor pressure
- Infrastructure
- Accessibility

Scores are prototype/demo indices unless backed by real verified data.

### Key issues

Translate data into actions.

Example:
Priority issue: Visitor pressure

Actions:
- avoid peak periods
- follow designated routes
- reduce waste
- respect local restrictions

### Responsible tips

Use destination-specific recommendations.

### Challenges

Show:
- challenge
- difficulty
- points
- estimated duration
- completion state

### Sustainable businesses

Show selected hospitality/business listings.

### Accessibility

Show structured accessibility information.

### Local/community

Show lightweight local experiences or community options.

### Traveler activity

Show recent responsible actions and challenge completions.

### Report issue

Prominent CTA:
Report a Destination Issue

## Search and filters

Useful filters:
- destination type
- budget where applicable
- accessibility
- sustainability
- distance only where location is available

Avoid building a huge booking search engine.

## Trust

Distinguish:
- platform index/demo data
- business-provided data
- traveler reports
- verified/partner data if implemented later
