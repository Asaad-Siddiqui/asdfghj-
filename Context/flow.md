# TRAVELLO — Product Flow

## 1. Core product loop

The central product loop is:

DISCOVER → ACT → PROVE → EARN → SHARE → INFLUENCE → IMPROVE

A traveler discovers a destination, receives practical responsible-travel recommendations, joins a destination-specific challenge, submits evidence, receives recognition, shares the achievement, and contributes information that can improve destination intelligence.

## 2. Public flow

Landing
→ Explore Destinations
→ Destination Preview
→ Login/Signup when an action requires an account

Secondary:
Landing → How It Works
Landing → Login
Landing → Signup

## 3. Traveler flow

Login
→ Home
→ Search/Explore
→ Destination Hub
→ Recommended Challenge
→ Challenge Details
→ Start Challenge
→ Active Challenge
→ Evidence Submission
→ Verification Result
→ Challenge Success
→ Share Achievement
→ Social Feed

A user may branch at almost any stage to:
- Profile
- Leaderboard
- Creators
- Businesses
- Report Issue
- Notifications

## 4. Destination flow

Home/Explore
→ Destination Search
→ Destination Card
→ Destination Hub

Destination Hub sections:
- Overview
- Sustainability
- Accessibility
- Responsible actions
- Challenges
- Businesses
- Local experiences
- Traveler activity
- Report issue

## 5. Challenge flow

Destination Hub
→ Challenge list
→ Challenge detail
→ Start
→ Active state
→ Complete
→ Evidence
→ Submit
→ Verification
→ Completion
→ Points/badge
→ Share

A challenge should not require unnecessary navigation steps.

## 6. Reporting flow

Destination or Home
→ Report Issue
→ Select category
→ Add description
→ Add photo
→ Capture/select location
→ Submit
→ Confirmation
→ Report status

Admin:
Report
→ Review
→ Categorize/priority
→ Dashboard aggregation
→ Status update

## 7. Creator flow

Creator Profile
→ Campaign
→ Campaign details
→ Join campaign

Creator:
Creator Dashboard/Profile
→ Create campaign
→ Select destination
→ Select or create responsible challenge
→ Publish
→ Followers discover campaign
→ Participants complete challenges

## 8. Business flow

Destination
→ Sustainable Businesses
→ Business card
→ Business profile

Business profile should explain sustainability and accessibility practices without pretending that a listing is independently certified unless it actually is.

## 9. Destination manager flow

Admin/Destination Manager login
→ Dashboard
→ Destination overview
→ Issue analytics
→ Issue list/map
→ Issue detail
→ Status update

The dashboard should turn traveler-generated observations into understandable intelligence.

## 10. Navigation

Primary traveler navigation:
- Explore
- Challenges
- Destinations
- Impact

Secondary:
- Creators
- Businesses
- Leaderboard
- Report Issue
- Notifications
- Profile

Mobile navigation should prioritize Explore, Challenges, Impact and Profile.

## 11. Demo story

The recommended hackathon demo is:

Traveler visits Matheran
→ sees sustainability/accessibility overview
→ receives Waste-Free Trail recommendation
→ starts challenge
→ submits photo + location
→ receives +25 points and badge
→ shares achievement
→ another traveler sees it
→ creator campaign shows participation
→ traveler reports a waste hotspot
→ destination dashboard displays the issue.

This is the primary narrative. Do not dilute it by demonstrating every possible feature.
