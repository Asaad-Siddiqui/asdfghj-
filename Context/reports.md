# TRAVELLO — Report & Protect Context

## Purpose

Travelers can contribute destination intelligence by reporting real-world issues.

## Categories

- Waste
- Accessibility
- Overcrowding
- Infrastructure
- Environmental damage
- Other

## Report form

Fields:
- category
- photo/evidence
- location
- description

System fields:
- reporter
- destination
- timestamp
- status

## Submission

Report Issue
→ category
→ evidence
→ location
→ description
→ submit
→ report ID
→ status

## Confirmation

Example:
REPORT SUBMITTED

Thank you for helping improve the destination.

Report ID: MRN-1024

Status: Under Review

## Report statuses

- Submitted
- Under Review
- Confirmed
- In Progress
- Resolved
- Rejected

## Dashboard aggregation

Reports should contribute to:
- issue counts
- category distribution
- priority areas
- map hotspots

Do not claim that a report automatically reaches a government authority unless a real integration exists.

## Priority

For prototype:
Priority can be derived from:
- category
- number of similar reports
- recency
- severity selected by reviewer

## Privacy

Do not expose reporter personal information unnecessarily.
